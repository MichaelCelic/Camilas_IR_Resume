# Campa's Scooperia

An interactive resume for Camila Campa, played like the opening of Papa's Scooperia. A visitor starts on a loading screen, then moves through the title, a save slot, and a character before the intro. After the video, the shop screen holds the resume.

## Shop buttons

- **Download Resume** saves `Camila Campa Resume.docx`
- **Projects**, **Experience**, **Education**, **Skills**, and **Contact** open the matching sections

## Run it locally

From this folder:

```bash
python -m http.server 8766
```

Then open http://127.0.0.1:8766/
